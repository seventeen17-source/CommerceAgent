# Development Log

本目录用于记录每次真实开发会话的轻量 devlog。目标不是写日报，而是保留后续 README、简历和面试复盘真正有用的事实。

文件名使用：`YYYY-MM-DD.md`。

## 模板

```markdown
# YYYY-MM-DD

## 今日目标
- 

## 今日完成
- [ ] 

## 遇到的问题
- 

## 关键决策
- 

## 今天学到
- 

## 下一步
- 

## Git 证据
- Branch: 
- Commit: 
- Tasks: 
```

## 记录原则

- 控制在 3–5 分钟内可写完；
- 重点记录“为什么这样设计”和“踩了什么坑”；
- 不虚构未完成工作；
- 不写隐藏推理过程，只记录可公开的设计理由、验证证据和结论；
- 一天可多次开发，继续更新同一天文件即可；
- 重要 A-class 学习内容应记录掌握点、失败模式和验证方式；
- Git branch / commit / task IDs 尽量保留，方便后续追溯。
