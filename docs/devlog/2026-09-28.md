## T030 — Agent 证据收集与受限 capability 决策收口

### 今日目标

### 今日完成

- 新增 request_understanding.py / OpenAI-compatible adapter：真实模型只输出 intent、mentionsLogisticsProblem、mentionedOrderId。
- 新增单候选订单解析：mentionedOrderId 只是线索；必须经过 Java get_order ownership 校验后才能成为 resolved_order_id；cross-owner / missing 继续统一为 ORDER_NOT_FOUND。
- 新增 decide_next_evidence：模型输出被收窄为 get_logistics 或 READY_FOR_ELIGIBILITY。

- 新增 read-tool execution + evidence normalization：只有成功 Tool 响应进入 EvidenceItem；stalledHours 继续由 Java 计算。
- 新增 eligibility handoff：READY_FOR_ELIGIBILITY 只表示结束证据收集；真正的 eligible / maxRefundAmount / approvalRequired 只来自 Java EligibilityService。
- 新增 dev/test-only POST /api/v1/agent/dev/t030/run，并叠加到同一个 Flow Playground 的 T030 · LIVE AGENT；这只是 live 验收 harness，正式 LangGraph 装配仍由 T032 完成。
