## 今天学到

- “可复用代码已经存在”不等于“当前 Task 已完成”；任务仍需按自己的定位、契约和 Gate 正式验收。
- eligibility 与 refund write 是两层：eligibility 负责回答“是否允许、允许什么、最大金额、是否需审批”；真正的 `requestedAmount` 属于退款写入阶段。
- 项目级 `AGENTS.md` / Learning Protocol 是开发顺序约束，不应在写代码后再补读。
