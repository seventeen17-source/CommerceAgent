# CommerceAgent UI Specification Skill

## Purpose

用于指导 Agent 在 CommerceAgent 项目中进行产品级 UI/UX 设计。

UI 设计必须服务于已有业务能力，而不是独立创造页面。

## Required Reading

设计前必须阅读：

- AGENTS.md
- .specify/memory/constitution.md
- PROJECT_PROGRESS.md
- 当前 feature spec
- contracts
- backend API
- agent runtime

## Workflow

1. Understand business capability
2. Identify user role
3. Define user problem
4. Design screen structure
5. Define data source
6. Define interaction
7. Define acceptance criteria
8. Implement UI

## Rules

禁止：

- 直接生成 CRUD 后台
- 自行创建业务接口
- 设计移动端 App
- 使用 AI 聊天窗口替代业务流程
- 暴露 hidden chain of thought

必须展示：

- Agent execution state
- Evidence
- Safety boundary
- Verification result
- Human collaboration
