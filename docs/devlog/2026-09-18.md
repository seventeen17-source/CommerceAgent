# 2026-09-18

## 仓库级 Map-first 教学协议

- 新增 `docs/LEARNING_PROTOCOL.md`，把“总体地图优先”从会话约定提升为仓库长期协议，不再依赖某个特定 Skill。
- `AGENTS.md` 的默认教学模式改为 **Map-first Project Teaching Protocol**：任何 Agent 开始 Txxx 前必须先说明当前阶段、系统层、上游、下游、输入、输出、解决的问题和最终 Agent 链路位置。
- 固定教学顺序：`总体地图定位 → 局部链路 → 核心概念 → 预测/checkpoint → 小步实现 → 验证 → 失败模式 → 面试压缩`。
- `project-coding-tutor` 保留为可选辅助 Skill；即使 Skill 不可用，仓库级教学协议仍必须执行。
- 更新 `docs/PROJECT_ARCHITECTURE.md` 的阶段映射：T015–T018 = Agent Runtime Foundation，T029 开始 Typed Tools，T030–T032 进入 Agent 决策与 LangGraph 核心。
- 目标：以后换 ChatGPT、Codex、其他 Agent 或新会话，只要读取仓库级指令即可恢复同一种带学方式。
- 本分支仅包含教学协议/架构说明文档，不包含 T016 hardening 代码。
