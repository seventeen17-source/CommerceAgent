# UI-1.0 验收与交接执行协议

## 两道独立门禁

Visual Gate：固定视口与数据对照视觉基准，组件状态符合pages.md。
Live Gate：真实身份→Web→Agent→Java→数据库→核验→UI。同一套组件，不能用演示截图冒充接线成功。

每次交付证据：branch/full commit、基线、页面ID、场景ID、视口、fixture版本、Run及业务资源、接口响应脱敏摘要、截图路径、命令退出码、实际通过/失败、限制。进度只更新PROJECT_PROGRESS，任务细节写tasks，历史devlog只追加。

## 固定截图条件

1600×1000主基准；1440×900、1280×800、390×844响应式。DPR1、100%缩放、字体已加载、禁动画、固定Demo时间/数据。Live截图记录真实时间，不伪装固定值。截图放docs/ui-evidence/<task>/<page>/<scenario>-<viewport>.png，证据清单放同目录README，不把它变成另一个进度表。

对照参考图：侧栏宽±4px，主区域边界±8px，间距遵守8px体系，字号按token；不得整体换布局、缩小文字塞一屏、隐藏核心区域。AI图片无法作为逐像素金标准；用明确尺寸和人工并排审查校验，首个通过的浏览器截图才作为像素回归基准。基准更新必须记录原因，不以更新快照掩盖回归。
