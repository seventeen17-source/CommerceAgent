- 进度判定固化为两步：**先固定 ref**（`git fetch` + 记录 `git branch --show-current` / `git rev-parse HEAD`），**再按五步回到代码**：生产实现 → 测试验证 → API/DTO/Schema → **生产调用链** → 持久化与工程接入。文档标记只用于定位阶段。
