### 架构位置

```text
Python Agent / CommerceClient
          ↓ HTTP
GET /api/v1/orders
GET /api/v1/orders/{orderId}
          ↓
OrderController          ← T023 HTTP boundary
          ↓
Spring Security          ← authentication / CUSTOMER capability
          ↓
OrderService             ← T019 ownership authority
          ↓
OrderRepository
          ↓
PostgreSQL
```

边界口径：
- 无/无效 JWT → 401。
- 已认证但非 CUSTOMER → 403 `ACCESS_DENIED`。
- CUSTOMER 访问自己的订单 → 200。
- CUSTOMER 访问别人的订单或不存在的订单 → 同样的 404 `ORDER_NOT_FOUND`。
