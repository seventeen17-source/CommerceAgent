## T016 Visible Output — Flow Playground V1

- Branch: `demo/t016-flow-playground`
- Purpose: turn the completed T016 Python→Java client boundary into a small visible, clickable teaching artifact before starting T017.
- Scope: **mock visualization only**. It does not claim that the real LangGraph Tool/FastAPI flow is already wired.
- Reuses the existing React/Vite app under `web/`; no new frontend dependency was added.

### What the page demonstrates

Fixed case: “我的耳机物流好久没动了，能退款吗？”

The flow visualizes:
1. `auth.py` → credential wrapping with `AuthContext`
2. `commerce_client.py` + `models.py` → `GET /me`
3. `identity.py` → fail-closed role resolution
4. order lookup
5. logistics lookup
6. eligibility evaluation
7. verified facts entering `AgentState`

Each step exposes three learning fields: **输入 / 做了什么 / 输出**.

Fault injection modes:
- unknown role
- logistics timeout
- unsafe `orderId`
- unknown Java-owned `allowedAction`
- traceId mismatch
- normal flow
